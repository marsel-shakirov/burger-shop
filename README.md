# Burger Shop

A responsive burger shop interface with a product catalog and shopping cart.

## Features

- Browse products from local mock data
- Add and remove products from the cart
- Change product quantities and calculate totals
- Navigate between the catalog, cart, and fallback page

## Tech Stack

- React and TypeScript
- Vite
- Tailwind CSS
- React Router
- Zustand

## Getting Started

```bash
npm install
npm run dev
```

## Available Commands

```bash
npm run build        # Create a production build
npm run preview      # Preview the production build
npm run lint         # Run ESLint
npm run format       # Format project files
npm run format:check # Check formatting
```

## Structure

The source code follows a Feature-Sliced Design-inspired structure: `app`, `pages`, `widgets`, `features`, `entities`, and `shared`.
